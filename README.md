# Amal Benny — Personal Website

A responsive, static personal portfolio based on the supplied resume.

## Files
- index.html — website
- styles.css — responsive styling
- script.js — light/dark theme toggle
- assets/amal.jpg — portrait extracted from the resume
- SEO-KEYWORDS.txt — SEO keyword plan and resume review

## Deploy
Upload the folder contents to any static host such as GitHub Pages, Netlify, Vercel, Cloudflare Pages, or your own web server.

The site currently uses https://alyod.tech/ as the canonical URL because that domain appears on the resume. Update the canonical and Open Graph URLs if the final domain is different.

## Before publishing
- Verify public contact details.
- Add real project links and GitHub if available.
- Add sitemap.xml and robots.txt.
- Consider adding a Projects page with case studies.
